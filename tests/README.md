# Tests

* `vectors/loader-requirements.json` — description-file cases shared with the All-Stars Mod Manager's checker: what the loader does and what the checker reports for the same file, and why they differ where they do.
* `native/` — the test programs and synthetic fixtures (a stand-in process at the game's image base, mod runtimes that only record calls, stand-ins for other loader releases). None contains game code or data.

How to build and run them, and what each one covers: [docs/BUILDING.md](../docs/BUILDING.md#tests).
